# Mémoire utilisateur — kit Project Manager V3

<!-- Ce fichier est chargé dans TOUTES vos sessions Claude Code quand ce dépôt est cloné comme ~/.claude.

- Le kit Project Manager V3 est installé dans ce dossier : skill `project-manager` (`/project-manager`, ou demande en langage naturel), agents spécialisés dans `agents/`, règle globale dans `rules/00-kit-workflow.md`.
- Dans un projet, la configuration du workflow vit dans `.claude/project-manager.config.json` ; sans elle, le PM demande quel registre de work items utiliser.
